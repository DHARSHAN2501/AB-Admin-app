# Smart Restaurant - Admin Management Dashboard 📊

Comprehensive restaurant operations and analytics dashboard for store managers.

## Features
- 📈 Live KPI metrics: Revenue, Active Orders, Table Turnaround, Cancellations
- 🍲 Menu management: Add/edit dishes, price adjustments, stock availability toggles
- 🏷️ Category organization & sorting
- 🪑 Table management & QR Code generation
- 👥 Customer history and reviews tracking

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment:
   ```bash
   copy .env.example .env
   ```
   Add your Supabase URL and Anon Key.
3. Start development server (Port 3002):
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
